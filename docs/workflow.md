# Workflow Argon2
1. `git pull origin main` antes de começar
2. Criar branch curta: `feat/nome-curto` ou `fix/nome-curto` ou `docs/nome-curto`
3. Fazer 1 mudança pequena e testar local
4. Commit claro: `feat:`, `fix:`, `docs:`, `test:`
5. Push + abrir Pull Request + pedir 1 review
6. Só merge após approval. Sem push direto na `main`
7. Nunca commitar `.env`, MAP_KEY, CSV grande
